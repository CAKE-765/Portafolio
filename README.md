# Portafolio personal

Sitio web personal para presentar mi perfil profesional, mis habilidades y algunos de los proyectos que he desarrollado.

## Contenido

- **Perfil profesional** (`index.html`): presentación, habilidades y datos de contacto.
- **Mis proyectos** (`mproyect.html`): galería de proyectos con enlaces a sus repositorios y demos.

## Tecnologías

- HTML
- CSS
- Bootstrap y Bootstrap Icons
- Tailwind CSS (mencionado entre las tecnologías usadas en algunos proyectos)

Bootstrap y Bootstrap Icons se cargan desde CDN, por lo que se necesita conexión a internet para ver esos estilos e iconos.

## Cómo ver el sitio

Abre `index.html` en un navegador. También puedes usar la extensión **Live Server** de Visual Studio Code para iniciar un servidor local y navegar entre las páginas.
